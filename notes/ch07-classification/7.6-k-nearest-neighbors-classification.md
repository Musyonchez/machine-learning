## 7.6 $K$-Nearest Neighbors Classification

Let $\tau = \{(\boldsymbol{x}_i, y_i)\}_{i=1}^n$ be the training set, with $y_i \in \{0,\dots,c-1\}$, and let $\boldsymbol{x}$ be a new feature vector. Define $\boldsymbol{x}_{(1)}, \boldsymbol{x}_{(2)}, \dots, \boldsymbol{x}_{(n)}$ as the feature vectors ordered by closeness to $\boldsymbol{x}$ in some distance $\text{dist}(\boldsymbol{x}, \boldsymbol{x}_i)$, e.g., the Euclidean distance $\lVert \boldsymbol{x} - \boldsymbol{x}' \rVert$. Let $\tau(\boldsymbol{x}) := \{(\boldsymbol{x}_{(1)}, y_{(1)}) \dots (\boldsymbol{x}_{(K)}, y_{(K)})\}$ be the subset of $\tau$ that contains $K$ feature vectors $\boldsymbol{x}_i$ that are closest to $\boldsymbol{x}$. Then the *K-nearest neighbors* classification rule classifies $\boldsymbol{x}$ according to the most frequently occurring class labels in $\tau(\boldsymbol{x})$. If two or more labels receive the same number of votes, the feature vector is classified by selecting one of these labels randomly with equal probability. For the case $K=1$ the set $\tau(\boldsymbol{x})$ contains only one element, say $(\boldsymbol{x}', y')$, and $\boldsymbol{x}$ is classified as $y'$. This divides the space into $n$ regions

$$\mathcal{R}_i = \{\boldsymbol{x} : \text{dist}(\boldsymbol{x}, \boldsymbol{x}_i) \leqslant \text{dist}(\boldsymbol{x}, \boldsymbol{x}_j),\, j \neq i\}, \quad i = 1,\dots,n.$$

*(☞ 142)* For a feature space $\mathbb{R}^p$ with the Euclidean distance, this gives a Voronoi tessellation of the feature space, similar to what was done for vector quantization in Section 4.6.

**Example 7.5 (Nearest Neighbor Classification)** The Python program below simulates 80 random points above and below the line $x_2 = x_1$. Points above the line $x_2 = x_1$ have label 0 and points below this line have label 1. Figure 7.6 shows the Voronoi tessellation obtained from the 1-nearest neighbor classification.

> **Figure 7.6:** A Voronoi tessellation of the 2D plane generated from 80 simulated points (blue dots labeled 0, above the line $x_2=x_1$; red squares labeled 1, below the line), with each point's Voronoi cell outlined. The 1-nearest neighbor algorithm divides up the space into Voronoi cells, and the cell boundaries roughly track the diagonal separating the two labeled point clouds.

```python
# nearestnb.py
import numpy as np
from numpy.random import rand,randn
import matplotlib.pyplot as plt
from scipy.spatial import Voronoi, voronoi_plot_2d

np.random.seed(12345)
M = 80
x = randn(M,2)
y = np.zeros(M) # pre-allocate list

for i in range(M):
    if rand()<0.5:
        x[i,1], y[i] = x[i,0] + np.abs(randn()), 0
    else:
        x[i,1], y[i] = x[i,0] - np.abs(randn()), 1

vor = Voronoi(x)
plt_options = {'show_vertices':False, 'show_points':False,
               'line_alpha':0.5}
fig = voronoi_plot_2d(vor, **plt_options)
plt.plot(x[y==0,0], x[y==0,1],'bo',
         x[y==1,0], x[y==1,1],'rs', markersize=3)
```
